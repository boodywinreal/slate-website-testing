Slate is a lightweight Linux distribution built around the musl C library, uses sinit, and comes with its own custom package manager.

## Features

- Uses musl libc
- Comes with its own package manager `slate`, written in POSIX shell
- Has a collection of source-based ports, containing a selection of lightweight software
- Installed minimal by default
- Has X11 support
- Supports cross-compilation
